# Changelog

All notable changes to a project's Core integration are recorded here.

Record at minimum:

- Contract version changes, including the version moved from and to.
- Conformance level changes, and what the conformance suite proved.
- Subscription changes, when a core entity is added to or removed from the mirror set.
- Contribution changes, when the project begins or stops contributing a core entity.
- Consumer behaviour changes that affect ordering, idempotency, or unresolved-reference handling.
- Staleness threshold changes.
