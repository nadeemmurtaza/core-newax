# Templates

This folder contains reusable documentation and structure templates for NEWAX Core.

Templates should help new modules, decisions, and standards start from a consistent shape before implementation begins.

No production code belongs in this folder.

## Templates

| Template                                                      | Purpose                                                                                               |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| [module-template](module-template/)                           | Structure every reusable NEWAX Core module must follow.                                               |
| [project-integration-template](project-integration-template/) | Scaffold a NEWAX project domain copies into its repository to integrate with the Core NEWAX Database. |
